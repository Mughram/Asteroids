# Asteroids

A simple Asteroids game built with Python and Pygame as part of the [Boot.dev](https://www.boot.dev) backend learning path.

## Features

- Player movement and rotation
- Shooting bullets
- Asteroids that split when hit
- Collision detection
- Game over on collision

## Installation

Clone the repository:

```bash
git clone https://github.com/Mughram/Asteroids.git
cd Asteroids
```

Install dependencies:

```bash
uv sync
```

Run the game:

```bash
uv run main.py
```

## Controls

- `W` / `S` - Move forward / backward
- `A` / `D` - Rotate
- `Space` - Shoot
